# گزارش تأیید بسته انتشار

این گزارش تاریخی آماده‌سازی بسته است. شواهد بعدی CI، staging سرور، نصب مجاز و محدودیت زنده Instagram در [ثبت نصب و پذیرش اولیه](DEPLOYMENT_ACCEPTANCE_FA.md) آمده‌اند؛ محدودیت CDN این محیط با شکست دسترسی زنده Instagram یکی نیست.

تاریخ بررسی: ۲۰۲۶-۱۱-۰۱. شاخه: `feature/instagram-page-inspector`. PR شماره ۱ merge نشده و هیچ اتصال یا تغییری روی سرور اصلی انجام نشده است.

## تفکیک و تغییرات

جدول PR_FILE_MAP_FA.md هر ۴۷ فایل اولیه نسبت به main را تفکیک می‌کند: ۳۹ فایل توسعه قبلی، ۶ فایل Inspector و ۲ فایل مشترک. ابزارهای انتشار جدید به این snapshot اضافه شده‌اند. کد کسب‌وکار پرداخت، SARPI، ایمیل و پنل ادمین در مرحله آماده‌سازی انتشار تغییر نکرده است.

بسته شامل builder، manifest هش فایل‌ها، staging مستقل، smoke آفلاین، نصب با backup معتبر و rollback کد و محیط است. وابستگی `tzdata==2026.6` نیز اضافه شد: در Ubuntu حداقلی بدون دیتابیس timezone سیستم، راه‌اندازی با خطای Asia/Tehran شکست می‌خورد و این وابستگی آن را رفع کرد.

تست‌های شکست عمدی، پیام‌هایی مانند Job failed یا INSTALL_OK چاپ می‌کنند؛ سرویس در این تست‌ها mock است و این پیام‌ها نشان‌دهنده اجرای نصب Production نیستند.

## موانع و پذیرش باقی‌مانده

دانلود Chromium رسمی Playwright در این محیط با HTTP 403 و «Domain forbidden» از CDN مسدود شد؛ دریافت image آماده Playwright از MCR هم محدود بود. نصب کتابخانه‌های سیستم مرورگر روی کانتینر Ubuntu انجام شد، اما اجرای bundled Chromium روی Ubuntu هنوز تأیید نشده است. موفقیت مرورگر سیستم در Debian جایگزین این پذیرش نیست. stage بدون مرورگر قابل deploy نیست و مانع را پنهان نمی‌کند.

پیش از نصب واقعی، staging پیش‌فرض را در Ubuntu با دسترسی مجاز به CDN اجرا کنید؛ browser smoke و ready.json با browser=true باید موفق شوند. مسیر فعال stage باید پایدار و زیر /opt/radepa-releases بماند.

ساختار فعلی سرور مستقیماً خوانده نشده است. نصب‌کننده فقط baselineهای شناخته‌شده و سرویس root با WorkingDirectory=/opt/radepa را می‌پذیرد؛ هر drift باید جدا بررسی شود. Python 3.11.0rc1 گزارش‌شده قدیمی سرور، در این بررسی آزمایش نشده است؛ برای انتشار از نسخه پایدار پشتیبانی‌شده استفاده کنید.

تست زنده Telegram، APIهای پولی و دسترسی واقعی صفحه Instagram در این مرحله اجرا نشده است. پس از مجوز نصب، پذیرش /start، پرداخت، ایمیل، پنل و /instagram لازم است. Inspector فقط صفحه ثابت بازیابی را بررسی می‌کند؛ نام کاربری نمی‌گیرد، فرم ارسال نمی‌کند و اطلاعات ماسک‌شده را استخراج نمی‌کند.

مراحل اجرا و بازگشت در RUNBOOK_FA.md هستند. manifest به commit سورس پیش از commit فایل ZIP اشاره می‌کند؛ commit صرفاً حاوی artifact، محتوای سورس بسته را عوض نمی‌کند.
