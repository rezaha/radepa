# نصب کنترل‌شده Sherlock روی ربات موجود

این مسیر برای درخواست بعدی مدیر جهت تست روی همان ربات آماده شده است؛ هیچ عملیات
واقعی روی سرور از محیط توسعه انجام نشده است. کد برنامه همان نسخه 531321f است.
نصب‌کننده جدید فقط app را تغییر می‌دهد. venv فعال، تنظیمات و دیتابیس حفظ می‌شوند.
نسخه پشتیبانی‌شده فعال، نسخه Menu با fingerprint
`2d6225790c6d177a9f11fe52ecf66b7523a1408e0819752a6fe7a9427d3e40fa` است؛ روی
نسخه ناشناخته توقف می‌کند. fingerprint نسخه جدید در نصب‌کننده ثابت است.

## مرحله اول: فقط پیش‌بررسی

سورس این شاخه را در مسیر جدا دریافت کنید و از پوشه `Radepa-server-review` اجرا کنید:

```bash
PYTHONDONTWRITEBYTECODE=1 /opt/radepa/venv/bin/python -m unittest discover -s tests -q
/opt/radepa/venv/bin/python -B tools/install_sherlock.py --stage "$PWD"
```

خروجی مطلوب `PREFLIGHT_OK ... NO_CHANGES` است. در این مرحله backup، stop یا start
انجام نمی‌شود. baseline، requirements، کاربر سرویس، ExecStart، Python پایدار، pip check
و وجود دیتابیس واقعی بررسی می‌شوند. هنگام خطا ادامه ندهید؛ guard را تغییر ندهید.

## نصب app پس از موفقیت پیش‌بررسی

```bash
/opt/radepa/venv/bin/python -B tools/install_sherlock.py --stage "$PWD" --apply
```

این دستور سرویس را کوتاه متوقف و راه‌اندازی می‌کند. قبل از آن از app، تنظیمات،
venv واقعی، پیکربندی سرویس و SQLite پشتیبان می‌گیرد؛ integrity و بازیابی روی کپی
دیتابیس بررسی می‌شوند. probe روی دیتابیس کپی انجام می‌شود. پس از stop، پشتیبان DB
تازه می‌شود. شکست نصب/راه‌اندازی باعث بازگردانی app قبلی می‌شود و تراکنش‌های جدید
از backup بازنویسی نمی‌شوند. مسیر `BACKUP` را نگه دارید.

قابلیت پس از نصب و در نبود تنظیمات قبلی همچنان غیرفعال است. پیش از فعال‌سازی، CLI
را با Python 3.10 در venv مستقل و ماندگار خارج از `/opt/radepa/venv` نصب کنید؛
مسیر آزمایشی `/tmp` برای نصب دائمی مناسب نیست. راهنمای `SHERLOCK_FA.md` تنظیمات
و آزمون CLI را توضیح می‌دهد. نسخه بسته باید `sherlock-project==0.16.2` باشد.

پس از تأیید CLI، کلیدهای SHERLOCK را در تنظیمات واقعی اضافه کنید، بدون تغییر بقیه
مقادیر؛ از توکن فعلی ربات استفاده می‌شود و polling دیگری نباید اجرا شود. تغییر env
نیازمند restart همان سرویس است. فعال‌شدن این قابلیت آن را برای کاربران ثبت‌شده و
غیرمسدود هم در دسترس می‌گذارد؛ حالت محدود به ادمین در این نسخه نداریم.

در تلگرام `/start`، دکمه راهنما و `/sherlock @YOUR_USERNAME` را بررسی کنید. خطا و
نتیجه ناقص با صفر موفق تفاوت دارند. تعداد لینک‌های احتمالی مالکیت حساب‌ها را اثبات نمی‌کند.

## بازگشت

در صورت نیاز با مسیر واقعی backup و ابزار ذخیره‌شده کنار همان پشتیبان:

```bash
/opt/radepa/venv/bin/python -B \
  /root/radepa-backups/REAL_BACKUP/tools/install_sherlock.py \
  --rollback /root/radepa-backups/REAL_BACKUP
```

این دستور app قبلی را برمی‌گرداند و دیتابیس، تنظیمات و venv فعال را نگه می‌دارد.
از installerهای قدیمی Menu یا support برای این نسخه استفاده نکنید.
