# بررسی منابع و امکان رفع 403 اینستاگرام

تاریخ: ۲۰۲۶-۱۱-۰۲. محدوده: صفحه ثابت /accounts/password/reset/، بدون ورودی نام کاربری، ورود به حساب، ارسال فرم یا استخراج اطلاعات تماس. منابع خارجی فقط خوانده شدند؛ کد یا skill خارجی نصب یا اجرا نشده است. این سند اصلاح پیام خطا را با رفع دسترسی مقصد یکی نمی‌گیرد.

## نتیجه

شواهد موجود، مشکل نبود کتابخانه یا اجرای Chromium را برای درخواست فعلی نشان نمی‌دهند: staging مرورگر موفق بوده، ولی هم Chromium و هم curl پاسخ 403 می‌گیرند؛ ssl_verify_result برابر صفر است. طبق پاسخ ارائه‌شده از پارس‌پک، پاسخ از مقصد بازگردانده می‌شود. هدرهای محدود دریافت‌شده فقط HTTP/2 403 و content-type=text/html را دارند. علت دقیق سیاست مقصد، IP، حساب یا نیاز احتمالی به context خاص از این شواهد قابل اثبات نیست.

در منابع بررسی‌شده راه‌حل معتبر و قابل‌تأییدی برای ارائه صفحه بازیابی به‌صورت API عمومیِ بدون ورود پیدا نشد. این نتیجه ادعای نبود هیچ نمونه‌ای در کل اینترنت نیست. بازیابی حساب، تحلیل محتوای عمومی و دسترسی API به حساب مجاز سه قابلیت متفاوت‌اند. جایگزین‌کردن نام کتابخانه، پشتیبانی مقصد را ایجاد نمی‌کند.

## منابع خوانده‌شده

### ۱. Playwright رسمی

commit مشاهده‌شده: `820620c98b359f4bb16e1596fd16d6b1a354b2f3`.

- [مستند page.goto](https://github.com/microsoft/playwright/blob/820620c98b359f4bb16e1596fd16d6b1a354b2f3/docs/src/api/class-page.md#async-method-pagegoto): کد HTTP ناموفق معتبر مانند 404/500 لزوماً navigation exception نیست؛ باید Response.status بررسی شود. همین اصل برای 403 صادق است.
- [Response.ok](https://github.com/microsoft/playwright/blob/820620c98b359f4bb16e1596fd16d6b1a354b2f3/docs/src/api/class-response.md#method-responseok): موفقیت HTTP با وضعیت 2xx سنجیده می‌شود، نه صرف بازشدن پردازش مرورگر.

اثر در Radepa: شرط response.ok و گزارش unavailable درست‌اند؛ locator یا انتظار بیشتر برای دکمه، پاسخ HTTP 403 را به 200 تبدیل نمی‌کند. اصلاح 165bd27 روی خطا دیگر DOM را نمی‌شمارد و اعداد صفر گمراه‌کننده را نمایش نمی‌دهد. این اصلاح هنوز روی Production نصب نشده است.

### ۲. Instaloader

commit مشاهده‌شده: `7acd1b6a75d9964b6e7bf91c0769e172e2a64359`.

- [معرفی پروژه](https://github.com/instaloader/instaloader/blob/7acd1b6a75d9964b6e7bf91c0769e172e2a64359/README.rst): ابزار محتوای پروفایل و رسانه است، نه SDK رسمی بازیابی حساب.
- [مدیریت پاسخ‌های HTTP](https://github.com/instaloader/instaloader/blob/7acd1b6a75d9964b6e7bf91c0769e172e2a64359/instaloader/instaloadercontext.py): مسیرهای جدا برای redirect ورود، وضعیت ناموفق، 429 و Forbidden در دانلود دارد.

کد، موفقیت همیشگی دسترسی ناشناس را تضمین نمی‌کند. 403 دانلود رسانه در این پروژه گاهی به امضای URL نسبت داده شده؛ نمی‌توان همان علت را به URL صفحه بازیابی Radepa تعمیم داد. این کتابخانه در این بررسی علیه اینستاگرام اجرا نشده است.

### ۳. Instagram List Inspector

commit مشاهده‌شده: `6e7c9e95fae5fb7997103eeee367e0271c02271b`.

[README پروژه](https://github.com/GreedyC/instagram-list-inspector/blob/6e7c9e95fae5fb7997103eeee367e0271c02271b/README.md) یک skill برای مقایسه فهرست‌های قابل مشاهده در مرورگر واردشده به حساب را توصیف می‌کند. ابزار مرورگر و حساب دارای دسترسی مجاز لازم‌اند. خود پروژه درباره ناقص‌بودن داده و توقف روی محدودیت‌ها توضیح می‌دهد و تأیید زنده همه قابلیت‌ها را ادعا نمی‌کند.

شباهت آن نام Inspector و گزارش شواهد است؛ جایگزین سرویس بدون ورودِ صفحه بازیابی نیست. این skill در محیط Radepa نصب یا اعمال نشده است.

### ۴. پروژه‌ای با نام Instagram Inspector و خروجی Telegram

commit مشاهده‌شده: `7de3e4ccb14db3f0ed877165280047a3c9368e5a`، مخزن `mehdiirh/instagram-inspector`.

README آن درباره تغییرات follower/following و اعلان Telegram است؛ پیکربندی و فرمان‌های ورود حساب دارد. مستندات آن مسیر حل تضمینی 403 صفحه بازیابی بدون ورود را ارائه نمی‌کنند. شباهت نام و خروجی تلگرام، به معنی یکسان‌بودن قابلیت نیست. این پروژه نصب یا اجرا نشد؛ ارسال رمز حساب از طریق فرمان‌های ربات برای Radepa پیشنهاد نمی‌شود.

### ۵. SDK رسمی Meta

commit مشاهده‌شده: `efd8423a2e595ea8d4c04eb824ce113f2f1d68cd`.

- [facebook-python-business-sdk](https://github.com/facebook/facebook-python-business-sdk/blob/efd8423a2e595ea8d4c04eb824ce113f2f1d68cd/README.md): دسترسی API بر مبنای access token و مجوز است.
- [مدل IGUser](https://github.com/facebook/facebook-python-business-sdk/blob/efd8423a2e595ea8d4c04eb824ce113f2f1d68cd/facebook_business/adobjects/iguser.py): فیلدهای name، username، biography، media_count و business_discovery و متدهای رسانه/insights را دارد. دسترس‌پذیری هر فیلد تابع مجوز و API است؛ وجود فیلد در SDK تضمین دسترسی به هر حساب نیست.

در منابع رسمی بررسی‌شده، قابلیت بازیابی تماس پنهان یا اثبات مالکیت مشترک دو حساب مستند نشده است. مسیر رسمی برای تحلیل حساب مجاز، پروژه جداگانه با طراحی مجوز و توکن است؛ رفع همان 403 یا جایگزین هم‌ارز Forgot Password نیست. صفحه کامل مستندات developers.facebook.com در policy این محیط مجاز نبود، بنابراین بررسی پلتفرم رسمی در این گزارش به سورس SDK محدود است و آمادگی اتصال واقعی API ادعا نمی‌شود.

## روش و محدودیت پژوهش

جست‌وجوی عمومی مخازن GitHub با عبارت‌های instagram playwright، instagram inspector و instagram playwright inspector انجام و منابع منتخب بالا در commitهای مشخص خوانده شدند. نتیجه جست‌وجو و نام پروژه به‌تنهایی شاهد کارکرد زنده نیست. جست‌وجوی مخزن با جست‌وجوی کامل کد GitHub یکی نیست؛ ادعای پوشش همه پروژه‌ها وجود ندارد. یک نام احتمالی fbsamples/instagram-api-sample-app یافت نشد و به‌عنوان منبع استفاده نشده است.

در این محیط github.com و raw.githubusercontent.com مجازند، اما www.instagram.com و developers.facebook.com مجاز نیستند؛ policy، proxy و TLS تغییر داده نشدند. درخواست زنده Instagram یا آزمون حساب از این محیط انجام نشد. شواهد سرور و پاسخ پشتیبانی توسط مدیر پروژه ارائه شده‌اند، نه مشاهده مستقل SSH دستیار.

## تصمیم برای نسخه فعلی

1. Inspector فعلی ابزار تشخیص دسترسی به صفحه ثابت باقی بماند؛ 403 با وضعیت بررسی‌نشده گزارش شود، نه صفر نتیجه یا اثبات نبود اطلاعات حساب.
2. تغییر گزارش 165bd27 از نظر تست‌های توسعه آماده است؛ نصب آن نیازمند release/staging تازه و بررسی baseline نسخه فعال است. فایل‌های stage فعال و manifest نباید درجا تغییر کنند.
3. درخواست رفع یا توضیح رد دسترسی مقصد از مسیر رسمی پیگیری شود؛ با شواهد فعلی رفع 403 در کد تأیید نشده است. هیچ راه‌حل حل‌شده یا تضمینی برای آن اعلام نمی‌شود.
4. اگر هدف محصول، تحلیل حساب مجاز یا داده‌های عمومی مجاز باشد، API و محدوده داده آن جداگانه طراحی شود؛ از مدل بازیابی برای شناسایی مالک ناشناس یا نتیجه‌گیری از تماس ماسک‌شده استفاده نشود.

در این پژوهش کد اجرایی، تنظیمات شبکه، دیتابیس و سرویس Production تغییر نکردند و PR merge نشد. تنها این گزارش و لینک آن به مستند موجود اضافه شده‌اند؛ تست زنده تازه‌ای اجرا نشده است.
